# Kawaii Skin · 樱花与星夜

给 Chrome 用的全站用户样式表：白天粉白、夜晚粉紫，不注入脚本、不发网络请求。
站点结构一律不动，只在外层加一张皮——弹窗、菜单、侧栏这类浮动面换成半透液态玻璃，
底下衬的是同一面粉。

## 装法

需要 Stylus 挂载：在扩展「详情」里勾上**允许访问文件网址**，把 `kawaii-skin.user.css`
的整个文件内容粘进 Stylus 新建的样式，保存即生效（面板那排开关就是全部配置项）。
必须走会自己求值 `@-moz-document` 的通道：实测 Chrome 154 自己的解析器会把外壳内的
规则整块丢掉，`--user-style-sheet` 那条路连摘了壳的表都不上色。

## 会改什么、让什么

改：页面底色与渐变花瓣、圆角、投影、正文与标题字色、滚动条/选区/焦点环、正文字体，
以及浮层的底和压在浮层上的字。让路：表格、真 `<button>` 与输入控件的背景边框。
站点自己涂了底、又没被接管那块底的地方字会撞色——切档，或关掉「标题垫底／链接描边」。
管不到浏览器界面，Shadow DOM 内部的底色也过不去（字靠继承跟得上）；开系统「减少透明度」
时浮层退回实心板。夹具与闸门一条命令跑完 `./tools/shoot.sh`，真站抽检 `./tools/spot-check.sh`。
